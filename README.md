# Prompt Composer TH→EN (v3)

เครื่องมือหน้าเว็บไฟล์เดียว ไม่มี backend ไม่ต้องใช้ API key ช่วยแปลและประกอบ prompt จากภาษาไทยเป็นอังกฤษ

## ใช้งาน

**หน้าแรก**
1. เลือกแบบสำเร็จรูป (หรือแบบ ⭐ ที่เก็บไว้เอง) หรือพิมพ์ไทยในช่องเอง
2. เลือกโหมด **คนเดียว**, **สองคน** หรือ **ฉากร่วม / หมู่** (2–6 คน: เลือกจำนวนคน กรอกรายคน กดปุ่มท่า ซีน สไตล์ภาพ ภาพถ่าย/ฟิล์มหนัง/POV)
3. กด **สร้าง prompt** แล้วกด **คัดลอกทั้งหมด**
4. หลายช็อตจะคั่นด้วย `----` ในบล็อกเดียว แต่ละช็อตเป็นบรรทัดเดียว

**วิธีใช้** มีปุ่ม "เริ่มสอน" ไฮไลต์ให้กดทีละขั้น และตัวอย่างพร้อมปุ่ม "ลองเลย"

**ตั้งค่า** ล็อกด้วยรหัส (ตั้งต้น `1234` เปลี่ยนได้) ใช้เติมคลังคำ แก้ส่วนหัว/ท้ายคงที่ จัดการแบบของฉัน ส่งออก/นำเข้า JSON

> รหัสเป็นเพียงตัวกันกดพลาดฝั่งเบราว์เซอร์ ไม่ใช่ความปลอดภัยจริง

## ทำงานยังไง

1. ใช้คำจาก **คลังของคุณ** ก่อน (จับคำยาวสุดก่อน) แล้วตามด้วยคลังพื้นฐานในตัว
2. ส่วนที่ไม่อยู่ในคลังแปลด้วย Google Translate (endpoint สาธารณะ) และ MyMemory เป็นตัวสำรอง
3. เรียงตามโครงของโหมด
   - คนเดียว: ตัวละครประจำ → สิ่งที่พิมพ์ → หมวดละเอียด → ส่วนท้าย
   - หลายคน: Person A / Person B / Interaction / Layout → ฉากแสงกล้อง
4. คำที่เครื่องแปลเองขึ้นเป็นปุ่มเหลือง กดแล้วเก็บเข้าคลังได้

## ปุ่มท่าและปุ่มซีนของคุณเอง

ตั้งค่า → เพิ่มปุ่มท่า/ซีนหลายรายการ วางทีละบรรทัดแบบ `ไทย=English` แล้วจะกลายเป็นปุ่มในโหมดฉากร่วมทันที คลังพื้นฐานในตัวมีซีน 10 แบบและท่าโต้ตอบทั่วไป ศัพท์ท่าเฉพาะทางเติมเอง

## อัปเดตจากเวอร์ชันก่อน

ใช้ชื่อไฟล์เดิม ทับ `index.html` และ `README.md` ได้เลย คีย์เก็บข้อมูลในเบราว์เซอร์ยังเป็นตัวเดิม คลังคำที่เคยเก็บไว้จึงไม่หาย แต่ควรกด "ส่งออก JSON" สำรองไว้ก่อนทับ

## ขึ้น GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`

## ข้อควรรู้

- ข้อมูลคลังเก็บใน `localStorage` ของเบราว์เซอร์ ไม่ถูกส่งไปเซิร์ฟเวอร์ใด ยกเว้นข้อความที่ส่งไปแปล
- endpoint ของ Google เป็นแบบไม่เป็นทางการ อาจเปลี่ยนหรือถูกจำกัดได้ MyMemory มีโควตาฟรีต่อวัน
- คลังพื้นฐานในตัวเป็นภาษาถ่ายภาพ (แสง ท่า ผ้า มุมกล้อง การปิดบังด้วยเงาและผ้า) ศัพท์เพิ่มเติมเติมเองผ่านตั้งค่า
