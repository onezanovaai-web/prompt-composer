# Prompt Composer TH→EN

เครื่องมือหน้าเว็บไฟล์เดียว (ไม่มี backend ไม่ต้องใช้ API key) ช่วยแปลและประกอบ prompt จากภาษาไทยเป็นอังกฤษ

## ทำงานยังไง

1. **คลังคำ (Glossary)** ระบบเช็กคำไทยที่คุณเก็บไว้ก่อนเสมอ (จับคำยาวสุดก่อน)
2. **ตัวแปลอัตโนมัติ** ส่วนที่ไม่อยู่ในคลังจะถูกแปลด้วย Google Translate (endpoint สาธารณะ) และ MyMemory เป็นตัวสำรอง
3. **ประกอบ** เรียงเป็นบรรทัดเดียวตามหมวด ท่าทาง → ชุด → ฉาก → แสง → กล้อง พร้อมส่วนหัว/ส่วนท้ายคงที่
4. หลายช็อตจะคั่นด้วย `----` ในบล็อกเดียว

## เพิ่มคำเข้าคลัง

- แท็บ **เพิ่มคำ**: พิมพ์ไทย → กด “หาคำอังกฤษ” → กดเลือกตัวเลือก (แก้ได้) → เลือกหมวด → เก็บ
- ตอนประกอบ prompt คำที่เครื่องแปลเองจะขึ้นเป็นปุ่มสีเหลือง กดแล้วเก็บเข้าคลังได้ทันที
- แท็บ **คลัง**: ค้นหา แก้ ลบ ส่งออก/นำเข้า JSON (ดูรูปแบบใน `glossary.sample.json`)

## ขึ้น GitHub Pages (ฟรี)

1. สร้าง repo ใหม่ แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)`
3. เปิดลิงก์ `https://<username>.github.io/<repo>/` บนมือถือได้เลย (เพิ่มลงหน้าจอโฮมได้)

ใช้งานแบบออฟไลน์ก็ได้ด้วยการเปิด `index.html` ตรงๆ แต่ส่วนแปลอัตโนมัติต้องมีอินเทอร์เน็ต

## ข้อควรรู้

- ข้อมูลคลังเก็บใน `localStorage` ของเบราว์เซอร์ ไม่ถูกส่งไปเซิร์ฟเวอร์ใดๆ ยกเว้นข้อความที่ส่งไปแปล ควรส่งออก JSON สำรองไว้เป็นระยะ
- endpoint ของ Google ที่ใช้เป็นแบบไม่เป็นทางการ อาจเปลี่ยนหรือถูกจำกัดได้ ส่วน MyMemory มีโควตาฟรีต่อวัน เมื่อคลังคำโตขึ้นจะพึ่งตัวแปลน้อยลงเอง
- ตัวแปลอัตโนมัติอาจแปลศัพท์เฉพาะหรือสแลงเพี้ยน จึงควรตรวจและเก็บคำที่ถูกต้องไว้ในคลัง
- ทุกคำศัพท์ในคลังเป็นของผู้ใช้เอง โปรเจกต์นี้ไม่มีคลังคำสำเร็จรูป มีเพียงตัวอย่างกลางๆ 4 คำ
