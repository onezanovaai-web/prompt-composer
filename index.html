สอนกดจริง

ระบบจะไฮไลต์ปุ่มให้กดทีละขั้นจนได้ prompt แรก

4 ขั้นตอนสั้นๆ

  1. หน้าแรก กดแบบสำเร็จรูป หรือ พิมพ์ไทยในช่องเอง
  2. กด สร้าง prompt
  3. กด คัดลอกทั้งหมด แล้วเอาไปวางในเว็บเจนภาพ
  4. ถ้ามีคำสีเหลือง ตรวจคำแปล แล้วกดเก็บเข้าคลัง ครั้งต่อไปจะได้คำแม่นขึ้น

ตัวอย่างการใช้ (กด “ลองเลย”)

โหมดสองคน และฉากร่วม/หมู่ ต่างจากคนเดียวยังไง

ต้องบอกให้ชัดว่าแต่ละคนเป็นใคร ใส่อะไร ท่าไหน ทั้งคู่ทำอะไรกัน และใครอยู่ตรงไหนในเฟรม เขียนสั้นและตรงจะได้ผลดีกว่าเขียนยาว เพราะแขนขาที่ซ้อนกันเป็นจุดที่โมเดลภาพพลาดบ่อย โหมดฉากร่วม/หมู่ให้เลือกจำนวนคน 2–6 กรอกรายคน แล้วกดปุ่มเลือกท่า ซีน และสไตล์ภาพ (ภาพถ่าย / ฟิล์มหนัง / POV) ระบบเรียงให้เองเป็นโครง Person 1, Person 2, … → Action → Layout → Setting → Style

แท็บ “สลับท่า”

มี prompt อยู่แล้วแต่อยากเปลี่ยนแค่ท่า วางลงในแท็บสลับท่า พิมพ์ท่าใหม่เป็นไทย เลือกคำอังกฤษที่ชอบ กดใช้ ระบบเปลี่ยนเฉพาะส่วน Action / Interaction ที่เหลือไม่แตะ

ข้อควรรู้

คำแปลอัตโนมัติอาจเพี้ยนกับศัพท์เฉพาะ จึงมีคลังคำให้เติมเอง ส่วนตั้งค่าล็อกไว้ด้วยรหัส (ตั้งต้น 1234) ข้อมูลทั้งหมดเก็บในเบราว์เซอร์เครื่องนี้

สลับท่า โดยไม่แตะส่วนอื่นของ prompt

วาง prompt ที่ประกอบเสร็จแล้ว (หลายช็อตคั่นด้วย ----) ระบบเปลี่ยนเฉพาะหัวข้อ Action / Interaction ส่วนตัวละคร ชุด ซีน แสง กล้อง สไตล์คงเดิมทุกตัวอักษร
